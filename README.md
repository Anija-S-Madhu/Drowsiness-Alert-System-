# AI-Based Real-Time Face Analysis System

## Description
This project is developed using Python, OpenCV, and MediaPipe to perform real-time face analysis through a webcam.

## Features
- Face Mesh Detection
- Blink Detection
- Smile Detection
- Head Pose Estimation
- Drowsiness Detection with Alarm

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Playsound

## Files
- face_mesh.py
- blink_detection.py
- smile_detection.py
- head_pose.py
- drowsiness.py

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run any module:

```bash
py face_mesh.py
```

or

```bash
py drowsiness.py
```
